# Security policy

## Supported versions

The latest released version receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([private vulnerability reporting](https://github.com/DrFritzi/schemacase/security/advisories/new)).
Do not open a public issue.

You can expect a first answer within a week. Relevant areas include escaping in the generated
page (spec content is untrusted input), the GitHub Action's handling of tokens and pull-request
content, and the importers' handling of connection strings.
